# Documentation Hub

This directory hosts reference material, architectural diagrams, onboarding guides, and contribution standards for the vscode-productivity-toolkit.

## Contents

- `getting-started.md` – Installation matrix covering scripts, the GUI installer, and the Smart Task Detector.
- `task-reference.md` – Summary tables for each task suite with links to their JSON definitions.
- `customization-examples.md` – Practical recipes for extending or composing toolkit automation.
- `video-tutorials.md` – Curated screencasts and resources to accompany written guides.
- `architecture.md` – High-level overview of system components and interactions.
- `faq.md` – Answers to common questions and misconceptions.
- `troubleshooting.md` – Step-by-step resolutions for frequently encountered issues.
- `contributing.md` – Contribution standards, code of conduct, and review expectations.

All documents are written with accessibility and internationalization in mind. Update the documentation whenever code changes may impact user workflows.
