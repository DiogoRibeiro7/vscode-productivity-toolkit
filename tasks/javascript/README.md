# JavaScript Tasks

This space is reserved for Node.js-based automation, VS Code task definitions, and npm tooling enhancements. Each task should be packaged as an executable script or documented VS Code task that can be invoked via the command palette or the CLI.

## Best Practices

- Use ECMAScript modules and follow the Airbnb JavaScript style guide.
- Declare dependencies in `package.json` files and pin versions to avoid drift.
- Provide linting and testing commands for every contributed script.
- Include examples demonstrating integration with the toolkit CLI or VS Code tasks UI.
