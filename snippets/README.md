# VS Code Snippets

Snippets accelerate repetitive workflows and encode team best practices. Import these JSON files into your global or workspace-level VS Code snippets directory to unlock shared commands and templates.

## Available Collections

- `python.json` – Dataclass scaffolding, logging boilerplate, and pytest helpers.

## Installation

1. Copy the desired snippet file into `~/.config/Code/User/snippets/` (Linux/macOS) or `%APPDATA%\Code\User\snippets\` (Windows).
2. Reload VS Code to register the snippets.
3. Trigger snippets using the defined prefixes (e.g., `logdebug`).

Contribute additional snippet packs by following the JSON structure demonstrated below and documenting the additions in this README.
