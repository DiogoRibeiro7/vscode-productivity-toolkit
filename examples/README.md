# Examples

This directory captures end-to-end workflows demonstrating how to compose toolkit capabilities.

## Available Recipes

- `workspace-bootstrap.md` – Step-by-step instructions for preparing a new repository using the toolkit.
- `productivity-comparison.md` – Quantified improvements observed when adopting the toolkit.
- `sample-projects/python-data-science/` – Data science starter workspace with curated task mapping.
- `sample-projects/react-dashboard/` – React analytics dashboard blueprint showcasing React task integrations.
- `integration/github-actions.md` – Example of mirroring tasks in GitHub Actions pipelines.
- `integration/docker-compose.md` – Docker Compose workflow aligned with toolkit automation.
- `tutorials/full-stack-pipeline.md` – Guided tutorial for building and shipping a full-stack application.
